## Core Engineering Principles

| Principle | In Practice |
|---|---|
| `Explainability First` | Every model decision traces back to a human-readable reason |
| `System, Not Script` | Modular architecture — ingestion, modeling, and interface are decoupled |
| `Validate Everything` | Programmatic checks on data integrity, model agreement, and output correctness |
| `Ship the Interface` | Dashboards and APIs, not just Jupyter notebooks |

## Featured Systems

<details>
<summary><b>🛡️ Explainable & Bias-Aware Phishing Detection</b></summary>
<br/>

**Interpretable Cybersecurity Analytics for Phishing Website Detection**

A phishing detection system built on interpretable classification — every flagged/unflagged decision traces to explicit, human-readable feature contributions rather than an opaque model score. Combines feature-level explainability with bias auditing across the decision boundary. Research on extending the bias-auditing methodology is ongoing.

**Key Capabilities**
- Interpretable feature attribution for every classification
- Bias-aware evaluation across the decision boundary
- Structured feature engineering from URL and page-level signals

**Technologies:** `Python` · `scikit-learn` · `SHAP/LIME-style explainability` · `Pandas`

**Status:** ✅ Completed &nbsp;·&nbsp; 🔬 Research extension ongoing &nbsp;|&nbsp; [`Repository →`](#)

</details>

<details>
<summary><b>🧭 AI Platform Sentiment & Migration Analytics</b></summary>
<br/>

**Multi-Model Sentiment Intelligence Across Generative AI Platforms**

An NLP analytics engine analyzing 50,000+ user reviews across five generative AI platforms — ChatGPT, Gemini, Claude, Copilot, and Perplexity. Five production-grade notebooks feed a unified Streamlit dashboard covering sentiment, topic structure, and cross-platform user migration behavior. Findings feed into ongoing research on trustworthy, explainable NLP evaluation.

**Key Capabilities**
- Multi-model sentiment consensus (VADER, TextBlob, RoBERTa) with Cohen's kappa agreement scoring
- Topic modeling via LDA and BERTopic to surface latent user concerns
- Migration-signal detection using regex extraction and directed-graph analysis (NetworkX)
- Aspect-based sentiment radar and a custom TWSI (Trust-Weighted Sentiment Index)

**Technologies:** `Python` · `NLTK/spaCy` · `Transformers (RoBERTa)` · `NetworkX` · `Plotly` · `Streamlit`

**Status:** ✅ Completed &nbsp;·&nbsp; 🔬 Research extension ongoing &nbsp;|&nbsp; [`Repository →`](#)

</details>
